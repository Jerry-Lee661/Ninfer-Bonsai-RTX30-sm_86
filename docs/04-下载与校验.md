# 下载地址与校验

## 一、预编译包（免构建）

文件名：`ninfer-serve-sm86-v0.1.0.zip`（812 MB）
SHA256：`717612c2ff0789b224ce6617b17306d9c778164be598bfda0f18819c05803c87`

内容：`ninfer-serve.exe`（ninfer-all + 本仓解析器修复，sm_86）+ ffmpeg/curl 运行库 +
两个起服脚本 + 上游 LICENSE/NOTICE + 包内 SHA256SUMS.txt。

运行环境要求：

1. NVIDIA 驱动 ≥ 550。
2. CUDA 12.8 运行时：把 `cudart64_12.dll` 与 `cublas64_12.dll` 放进包目录或 PATH
   （装了 CUDA Toolkit 12.8 就有，在 `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.8\bin`）。
3. VC++ 2015-2022 x64 运行库（MSVCP140.dll 等）。

包内各文件 SHA256 见包内 `SHA256SUMS.txt`（其中 `ninfer-serve.exe` =
`e87093af77cf2084...` 开头，完整值在文件里）。

## 三、把预编译包挂到 GitHub Release

本机没有可用的 GitHub 凭据，上传需要你执行一次。两种方式：

方式 A（网页）：进入仓库的 Releases，新建标签 `v0.1.0`，把
`RELEASE_NOTES_v0.1.0.md` 内容粘进说明，然后把 `dist/ninfer-serve-sm86-v0.1.0.zip`
拖进附件区上传。

方式 B（命令行，需要 gh 与登录）：

```bat
gh release create v0.1.0 dist\ninfer-serve-sm86-v0.1.0.zip ^
  --title "v0.1.0 首个可运行版本" ^
  --notes-file RELEASE_NOTES_v0.1.0.md
```

或者：把 Personal Access Token 交给本工程的操作者，直接由脚本推送并创建 Release。
